# ATM Fraud Detection and Risk Analysis System

A SQL-based ATM fraud detection and risk analysis project developed using MySQL.

## Technologies
- MySQL
- SQL
- MySQL Workbench

## Features
- ATM transaction monitoring
- Fraud alert detection
- Risk score calculation
- Account risk classification
- Fraud and risk analysis using SQL
- Stored procedures and views

## Database
Database: `atm_fraud_analysis`

## Project File
`atm_fraud_analysis.sql`
